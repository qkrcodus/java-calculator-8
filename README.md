# java-calculator-precourse

## ✨ 구현할 기능 목록

### 입력

- [X] 사용자의 문자열 입력을 `Console.readLine()`으로 받는다.

### 문자열 파싱과 숫자로 변환

- [X] 쉼표(,) 또는 콜론(:)으로 구분된 문자를 분리한다.
- [X] `"//"`와 `"\n"` 사이 문자를 커스텀 구분자로 인식한다.
    - 예: `//;\n1;2;3` → 구분자 `;`
- [X] 구분자로 분리된 문자열을 숫자로 변환한다.

### 계산

- [X] 모든 숫자의 합을 계산한다.

### 예외 처리

- [X] 음수 또는 숫자가 아닌 값 입력 시 `IllegalArgumentException` 발생
- [X] 예외 발생 시 프로그램 종료 (`System.exit()` 미사용)

### 출력

- [X] 덧셈 결과를 `"결과 : n"` 형식으로 출력한다.
